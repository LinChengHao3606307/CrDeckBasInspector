Browser Auto API检测服务中…

左侧是真浏览器，右侧实时记录所有往来流量；下方接口按端口配置提供服务。

接口速览

GET/current/
返回当前页面 URL、标题与完整 HTML

GET/element/?selector=<css>
返回所有命中元素的坐标（视口 CSS 像素）

POST/mouse/
move / click / dblclick / down / up / drag / wheel
移动轨迹为贝塞尔曲线手滑，非直线
端口在右侧“服务配置”里修改，默认 8765；启动后同目录生成 config.json 保存设置。

鼠标示例

# 移动
curl -X POST http://127.0.0.1:8765/mouse/ \\
  -H "Content-Type: application/json" \\
  -d "{\"action\":\"move\",\"x\":400,\"y\":300}"

# 点击（也可以只给 selector）
curl -X POST http://127.0.0.1:8765/mouse/ \\
  -d "{\"action\":\"click\",\"selector\":\"#demo-btn\"}"
点击使用真实 Qt 鼠标事件，链接跳转、表单、焦点、悬停都是浏览器原生行为。
